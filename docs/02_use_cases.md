# Use Cases

The mechanism is not the product.

The failure-metabolizing boundary is the product.

## Coding Or Patch Routing

- attempts
  build tries, patch tries, tool selections
- vault
  failed routes, blocked surfaces, missing prerequisites
- constraints
  avoid this route under these conditions

## Workflow Recovery

- attempts
  stage transitions, handoffs, recovery steps
- vault
  stalled transitions, invalid prerequisites, blocked dependencies
- constraints
  do not advance under these conditions

## Tool Orchestration

- attempts
  choosing a tool, host, or method
- vault
  wrong tool classes, repeated dead-end selections
- constraints
  block known bad tool posture

## Experiment Loops

- attempts
  trial variations
- vault
  failed parameter regions
- constraints
  fence off low-value or structurally bad search regions
